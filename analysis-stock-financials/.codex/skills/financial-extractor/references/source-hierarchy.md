# Source Hierarchy

Prefer sources in this order:

1. investor relations pages
2. annual reports or audited financial statements
3. official filings
4. earnings releases or earnings presentations
5. company-provided downloadable tables
6. user-supplied CSV copied from official source
7. secondary data providers for market ratios only

Rules:

- Resolve conflicts by preferring the higher-ranked source.
- If you use a lower-ranked source, say why.
- If you cannot resolve a conflict honestly, record the conflict and mark the affected value unavailable.
